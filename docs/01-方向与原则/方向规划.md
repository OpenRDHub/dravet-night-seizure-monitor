# 方向规划 ｜ Dravet 夜间监护（赛题 05）

时间：2026-09-26 ｜ 距开赛（10/15）19 天 ｜ 状态：方向定稿前，暂不写代码

依据：出题患者家长的 PRD-0921、通用知识文档 0918、5 分钟需求讲解稿、卓蔚宝贝睡眠发作问卷统计（151/149/98/97/96/66 人）

---

## 一、产品目标（已确认）

**让家长和孩子都能睡好。手段是把误报压下去。**

补充一句边界：漏掉的东西不靠"半夜叫醒家长"来兜，靠**次日报告**兜。这样"少误报"和"不漏"就不打架了——
**夜里只报该报的，其余的白天全部看得见。**

为什么误报是硬指标：误报不只是吵醒，它会让家长**脱敏**（患者文档原话："误报频繁导致家长疲劳脱敏"）。脱敏之后真出事他也不起来——所以压低误报同时是睡眠设计和安全设计。

---

## 二、核心价值主张（已确认）

> 别的设备是让家长睡在孩子旁边更安心；**我们做的是让家长能回自己床上睡。**

来源：问卷开放题原话——"不敢让孩子独自睡觉，怕发作了发现不了，而有生命危险，可孩子又大了总不能一直和父母睡吧"；5 分钟讲解稿——"孩子长到十几岁生理上必须分床、分房独立睡眠，但没有任何一位家长敢真正放手"。

**所以"让孩子独立睡、让家长回自己床上"不是附加功能，是产品的核心目的之一。**

---

## 三、场景范围（已确认）

第一版**只做夜间睡眠**，覆盖三种睡眠布局：

| 布局 | 提示走哪里 | 提示强度 | 触发门槛 |
| --- | --- | --- | --- |
| 同床陪睡 | 家长手环（轻震） | 最轻：抬头看一眼 | 最低（成本低，可以更灵敏） |
| 同房分床 | 家长床边设备 + 手环 | 中等：能叫醒，不吵孩子 | 中等 |
| 分房独立睡 | **家长房间设备 + 手机**（孩子房间仍零声光） | **必须能真正叫醒** | **最高**（代价大：起床 + 走过去 + 这一晚基本废了） |

关键账：分房时，**有效干预时间 = 检测时间 + 叫醒家长的时间 + 走过去的时间**。黄金时间只有 5 分钟，走过去可能占 30–60 秒，所以分房模式下判定窗口必须压得更短、提示更快。

有利条件：**"零声光"只约束孩子所在空间**。家长房间可以正常出声发光，分房场景的报警手段反而更多。

## 五、判断规则的四条原则（大白话，不写代码）

1. **用这个孩子自己的正常数据当尺子**——先跑几晚学他"正常什么样"，偏离他自己才算异常。
2. **要几条信号一起变才算**——只翻身 → 只记录；翻身 + 呼吸变了 + 心率升了 → 才提示。
3. **要持续一段时间才算**——几秒钟的波动不报，持续 20–30 秒才提示；二级在 60 秒内升级。
4. **家长一键标记"这是误报"**——标一次，系统下次就知道这类不算，越用越准。

## 六、成绩单（不叫检出率，叫这两个数字）

| 指标 | 目标 |
| --- | --- |
| 一晚被打扰几次 | ≤ 1 次（可让家长自选上限） |
| 家长连续睡眠 ≥ 4 小时的天数比例 | 逐月上升 |
| 从事件发生到提示发出的延迟 | 一级 ≤ 30 秒；二级 ≤ 60 秒 |

## 七、第一版不做（写进方案反而是加分）

- 血氧（非接触不可靠，指夹破坏无感定位）
- 白昼午睡 / 外出 / 运动等碎片场景
- 发热高危模式（家长文档里本身就写的是"后续希望"）
- 手机原生 App（19 天做不完）
- 多人协同的完整实现（只演示家长端 + 记录页）
- 临床验证与检出率宣称

## 九、要问家长的三个问题

1. 一晚最多能接受被叫醒几次？（这个数字直接决定报警门槛）
2. 一级提示要不要震动，还是只要记录、第二天看？
3. 复诊时最想让医生看到什么？（决定那页报告长什么样）

---

## 十、现场演示要证明的三件事

1. **更早**——不等孩子抽起来，呼吸变了就提示。
2. **只打扰家长，绝不打扰孩子**——孩子房间零声光，提示走家长端触觉，并按睡眠布局自动调整强度。
3. **漏掉的次日一定看得见**——整夜异常总量 + 一页给医生的记录。
