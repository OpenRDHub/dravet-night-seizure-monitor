# 技术文档索引

本文档集是「罕见·无界」黑客松 **赛题 05（Dravet 综合征夜间无感睡眠监测预警设备）** 的技术探索记录。

赛题仓库的 `README.md` 是出题方撰写的《产品需求书 V1.0》，描述**要做什么**；
本目录记录的是参赛团队在**怎么做**上的分析、决策与依据。

---

## 一句话方案

**以非接触毫米波雷达为主通道**，采集呼吸、心率、体动、在床状态；**手环作为第二输入通道**（阵挛确认 + 心率交叉验证）。
核心创新不在"毫米波 + AI + 睡眠监测"（该组合已有医疗级产品），而在 **夜间发作事件检测 + 家长看得懂的分级提醒** 这一层。

设计目标不是"更准的报警器"，而是 **让家长能睡着的守夜替班**：夜里只报该报的，其余靠次日报告呈现。

## 报警阈值口径

以下阈值**全部转述自临床访谈**，非团队自定数值：

| 指标 | 阈值 | 备注 |
| --- | --- | --- |
| 心率 · 大发作 | 比基线增高 **30–60 次/分**，持续 **>45 秒** | 医生经验值，后续随数据积累调整 |
| 心率 · 持续异常 | 持续低于 60 次/分达 **5–10 秒** | |
| 呼吸 | 发作期暂停 **10–30 秒** | ⚠️ 家长口径为 30–60 秒，两处不一致，**待向医生确认** |
| 血氧 | 发作后 **50–60 秒**延迟下降 | 本期不做采集 |
| 体动 · 阵挛 | 抽动间隔 **1–3 秒**或 **1–5 秒** | 发作初期较快，临近结束变慢 |
| 长时发作 | 持续 **>2 分钟**必须报警 | 防致死性风险 |
| 发作后监护 | 结束后维持 **5–10 分钟**高风险监测 | 防呼吸心跳骤停 |

**监测目标限定为惊厥性发作**（强直阵挛、阵挛、强直）。非惊厥性发作（肌阵挛、失神）不设报警，仅作事件记录以完善癫痫日记。

## 数据与隐私边界

本仓库**不包含**任何患者隐私材料：

| 材料 | 是否公开 | 说明 |
| --- | --- | --- |
| 《产品需求书 V1.0》 | ✅ 已在仓库 README | 出题方撰写，公开 |
| 病友问卷**统计结论** | ✅ 本文档引用 | 如"靠设备报警发现发作仅 1%" |
| 病友问卷**原始答卷**（含家长亲述文本） | ❌ 不公开 | 与患者隐私相关 |
| 医生访谈**全文** | ❌ 不公开 | 含真实姓名与临床细节 |
| 医生访谈**结论性口径** | ✅ 本文档引用 | 阈值、适用发作类型、技术局限 |
| 患者家庭信息、联系方式 | ❌ 不公开 | |

依据赛手手册：患者隐私、医疗数据、个人身份信息、未经授权的医学资料**不属于**必须公开的内容，开源不等于公开患者隐私。
需要原始材料的社区成员，请在赛事知识库内经授权查阅。
