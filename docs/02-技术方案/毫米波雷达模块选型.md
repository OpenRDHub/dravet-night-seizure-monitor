## 一、先说结论

1. **赛题要的四路信号，一颗雷达包不了。** 体动、呼吸能拿到，心率只能算"输出里有、可靠性看场景"，**血氧任何毫米波雷达都测不了**。
   2026-09-26 决定：**本期不做血氧**（指夹会破坏"无感"定位、儿童依从性差；血氧是严重程度指标，不承担发作识别作用），列为后续可选扩展。
2. **市面上没有任何模块做"癫痫发作检测"。** 所有模块输出的都是存在/体动/呼吸/心率/睡眠状态/跌倒。从这些信号推到"疑似发作事件"，**那层算法就是你项目唯一不可替代的部分**。
3. **路线建议**：
   - **A 线（推荐，19 天可交付）**：成品生命体征模块 → 直接读呼吸/心率/体动 → 自研事件检测 + 分级提醒 + 记录卡。整机成本 ¥200–400 级。
   - **B 线（技术含量高，风险高）**：取点云/1D2DFFT 原始数据的模组 → 自己写信号处理。30 元级就能起步，但 19 天内做出可用效果的概率低。
4. **竞品已经存在**：清雷科技（清华成果转化）已做出医疗级毫米波雷达睡眠呼吸障碍 AI 诊断系统。**答辩时不要把"毫米波 + AI + 睡眠监测"当创新点**，创新点必须落在"夜间发作事件检测 + 家长看得懂的分级提醒"。

**关键判断**：现有玩家集中在"睡眠呼吸暂停筛查/跌倒/婴儿看护"。**癫痫夜间发作检测是空位**，原因也清楚——真正确认发作靠脑电（24 小时脑电/多导睡眠监测），雷达只能提供替代信号。这既是你的机会，也是评委会追问的点。

## 四、赛题四路信号覆盖度

| 赛题要求 | 雷达能否提供 | 说明 |
| --- | --- | --- |
| 体动 | ✅ | 雷达最擅长，微动也能测 |

| 心率 | ⚠️ | 模块输出里常带，但受距离、体位、被子遮挡影响大，厂商指标多在成人静卧无遮挡下测得 |
| 血氧 | ❌（本期不做） | 雷达原理上测不了，非接触血氧也没有可靠方案。列为后续扩展 |

## 七、下一步（按优先级）

1. 定 A 线，选一颗模块下单（Seeed MR60BHA2 套件最省事：模块 + ESP32 + 官方库 + 现成例程）。
2. 拿模块后先做"能读数的 Demo"：实时显示体动强度、呼吸率、心率三条曲线——这就是赛前能预制的最大一块。
3. 在这三条曲线之上写事件检测规则（如：体动强度突增 + 呼吸节律紊乱 + 持续 > 30 秒 → 升一级提示）。
4. 本期只做三路（体动 / 呼吸 / 心率）；材料里如实写"血氧作为后续扩展，本期不在范围内"。
5. 把清雷科技写进竞品分析，明确差异化：他们做睡眠呼吸障碍筛查，你做夜间发作事件检测与家长沟通层。
