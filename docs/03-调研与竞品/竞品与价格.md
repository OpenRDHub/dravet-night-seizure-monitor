## 一、一句话结论

市面上的方案分四条技术路线：**佩戴式运动/生理信号**、**床垫式非接触**、**医用脑电**、**雷达非接触**。
其中**没有一款在售产品是"非接触雷达 + 癫痫夜间发作报警"**——这是真正的空位。
但现有产品的**精度和资质我们完全比不过**，所以优势只能建立在"无感 + 多维信号 + 家长沟通层 + 成本"上，不能建立在精度上。

## 三、NightWatch+ 细节（最直接的对标产品）

来源：官方站点 livassured.com / nightwatchepilepsy.com【已核】

- **原理**：无线传感器戴在手臂上，用**心率 + 运动**持续监测，检测到危险发作时无线通知家长端的报警基站；可选联网到 NightWatch Portal 查看整夜数据。
- **适用人群**：确诊癫痫、**4 岁以上**、有夜间运动性发作者。
- **能检测的发作类型**：全身强直阵挛、强直（成簇或延长）、过度运动性、肌阵挛（成簇）。
- **官方公布的灵敏度**：所有主要运动性发作类型中位数 **成人 86% / 儿童 100%**；强直阵挛 **成人 96% / 儿童 100%**（>4 岁）。验证方为荷兰 SEIN 癫痫中心与 Kempenhaeghe 学术中心，累计数千个夜晚。
- **规模**：官网称已有 10,000+ 家庭使用。
- **价格**：官网不给价，走试用/询价——医疗级产品的常态。

**对我们的意义**：这是"精度天花板"的参照物。答辩时如果有人问"你们和 NightWatch 比怎么样"，正确回答是"我们不与它比精度，它解决的是戴得住的人的报警，我们解决的是不戴也要有数据这一环"。

**结论**：医疗级产品普遍不公开零售价（询价/租赁/医院渠道）；消费级与模块级才有公开价格。这直接影响我们的定价策略——我们的比较对象应该放在消费级（手环、睡眠垫）与模块成本上，而不是跟医疗级比价。

## 五、我们能做出来的三个真优势

1. **无感 + 多维信号，这个组合目前没人做。**
   佩戴式（NightWatch、Embrace）要多维信号就得戴；床垫式（Withings、癫痫报警器）不用戴但只有体动/呼吸/心跳，维度少。雷达是唯一"不用戴"又能同时给出**体动 + 呼吸 + 心率 + 距离**的路线。

2. **成本结构低一个数量级。**
   核心雷达模块 30–300 元级，整机 BOM 可以压在几百元。医疗级方案是询价制（数千元级起步、多走医院渠道），消费级手环虽几百元但每天要充电、必须戴在手上。

3. **中文家长沟通层是现有产品都没做的那一环。**
   现有产品的输出是"报警"——响了，然后呢？而国内家长的真正痛点是"这说明什么、要不要现在去医院、怎么跟医生讲"。我们已有的三段式输出（情况说明 / 紧急程度 / 建议动作）+ 就诊记录卡，正是这一环，而且 3 天能做出来。

## 六、必须承认的三个劣势

1. **精度比不过。** NightWatch 儿童强直阵挛 100%、成人 96%，经数千夜临床验证；我们的儿童数据是零，灵敏度未知。**精度绝不能当作卖点。**
2. **没有资质。** NightWatch 是欧盟 MDR Class IIa、ISO 13485；国内同类按 Ⅱ 类器械管理。我们目前什么都不是，所以只能叫健康管理/提示工具，不能声称医疗用途。
3. **雷达有物理局限。** 金属、厚被子、宠物、旁边有人都会干扰；血氧测不到，且非接触血氧没有可靠方案（本期决定不做血氧）。

## 七、定位建议与答辩话术

**定位一句话**：不做"更便宜的发作报警器"（会被精度打死），做"**无感采集 + 家长沟通层**"。

三句备用话术：

- "现有方案要么必须戴在身上，要么只有单一维度的信号；我们做的是不戴也有多维数据这条路。"
- "我们不与经临床验证的报警设备比灵敏度，我们解决的是它报警之后的那一段——家长看不懂、医生问不清。"
- "我们的定位是健康管理与就医辅助，不做诊断，所以不宣称检出率，只输出疑似提示和记录。"
