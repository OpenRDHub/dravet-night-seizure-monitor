# Dravet Night Seizure Guard · Dravet 综合征夜间睡眠监护设备

> 「罕见·无界」黑客松 · 赛题5 · Dravet 综合征夜间癫痫睡眠监测设备
> 依据《Dravet 综合征夜间睡眠监护设备 产品需求书 V1.0》（2026-10-01）编写 · 依据：2024 Dravet 综合征专家共识、全国 150+ 病友问卷调研、医生访谈 · [OpenRD 罕见病开源社区（Khub）](https://github.com/OpenRDHub)

**Dravet 综合征患者夜间安全监护辅助系统**：用于居家夜间睡眠高危发作、异常体征识别与照护辅助。非医疗诊断设备、不替代脑电图、不替代医生诊疗、不承诺杜绝 SUDEP。核心价值：**减少漏检、降低误报、减轻照护压力、沉淀病情数据**。

> 让每一位 Dravet 孩子能够安心独立入睡；让每一位常年紧绷的罕见病家长，终于能睡一个安稳觉。

## 🧭 一、疾病背景与核心痛点

Dravet 综合征是 SCN1A 基因突变导致的婴儿起病、终身性、难治性癫痫脑病，属国家第一批罕见病，国内现存患者约 3–5 万人。**六大高危特征**：

1. **热敏感**：37.3°C 以上低热即可诱发发作
2. **多类型发作**：惊厥性、非惊厥性、肌阵挛、失神等
3. **极易持续**：常进展为癫痫持续状态
4. **夜间睡眠期高发**：10 岁左右发作重心转移至睡眠期
5. **隐匿发作多**：无明显抽搐，仅心率/呼吸异常
6. **SUDEP 风险高**：夜间猝死核心体征为心跳呼吸骤停

| 核心痛点 | 现状 | 后果 |
|---|---|---|
| 隐匿发作漏检率极高 | 家长仅通过孩子疲惫、出汗、外伤后知后觉 | 脑损伤、缺氧、甚至猝死 |
| 通用设备识别逻辑不匹配 | 普通手环只识别大幅体动，非惊厥发作 100% 漏报 | 真正高危事件被忽略 |
| 误报过多导致监护脱敏 | 翻身、做梦频繁报警，家长疲惫麻木 | 真实高危事件反而被忽略 |
| 家长长期无法深度睡眠 | 整夜浅眠值守、轮流熬夜 | 家庭照护负担极大，身心透支 |
| 多人照护信息断层 | 轮班无统一记录，信息不同步 | 复诊调药缺乏数据支撑 |

**市场空白**：国内成熟的二类医疗器械（如依瑞通 S2 癫痫腕表，售价 2–4 千元）基于普通癫痫人群训练，无法可靠检出 Dravet 特有的安静隐匿发作；海外医疗设备（NightWatch、EmbracePlus）同样存在此盲区。**目前市面上没有任何一款设备适配 Dravet 的夜间风险。**

## 🛠 二、核心功能需求

### 1. 多维度体征融合识别（不依赖单一肢体动作）

| 监测维度 | 识别特征 | 技术指标 |
|---|---|---|
| 心率 | 异常波动、骤升、持续异常 | 发作时增高 30–60 次/分，持续 >45 秒触发报警 |
| 呼吸 | 节律紊乱、短暂停顿、深浅异常 | 发作期呼吸暂停 10–30 秒 |
| 血氧 | 延迟性下降 | 发作 50–60 秒后出现变化，准确率极高 |
| 体温 | 异常波动、骤升 | 37.3°C 以上低热即可诱发发作 |
| 体动 | 异常节律（抽搐、阵挛） | 阵挛抽动频率 1–3 秒或 1–5 秒间隔 |

算法要求：可识别**有抽搐大发作 + 无抽搐隐匿小发作**；区分正常翻身、睡眠抖动、做梦微动与病理性异常；严控误报；**个体化基线**（佩戴一段时间记录无发作夜间平均心率作为报警基线）。

### 2. 分级预警系统

- **一级预警（疑似隐匿小发作/轻度体征异常）**：无明显抽动但持续心率呼吸异常、睡眠中细微肌阵挛、「发呆僵住」呼吸轻微停顿等 → 低打扰提醒（柔和灯光、App 静默推送），孩子房间设备完全静默零打扰，供家长自主复核
- **二级预警（高危惊厥发作/疑似持续状态）**：节律抽动、持续异常体征、长时间未恢复 → 本地声光升级报警+手机紧急推送，多监护人同步接收；房间仅保留极柔和低亮灯光，无刺耳蜂鸣
- **长时发作报警**：持续发作超过 **2 分钟**必须提醒家长，防致死性风险
- **发作后高风险期**：单次发作结束后保持 **5–10 分钟**高风险监测，预防呼吸心跳骤停及发作后呼吸抑制

### 3. 夜间事件自动记录时间轴

自动留存每一次可疑事件时间点、持续时长、体征变化特征、日/周发作趋势汇总——解决多人照护信息不对称，可作复诊调药与病情复盘参考。

### 4. 多家庭成员协同管理

多名监护人账号绑定，事件与报警记录全员实时同步，轮班照护无缝衔接。

### 5. 全夜间低刺激安全机制（Dravet 特性适配）

患儿光敏、刺激易诱发发作：禁止高频闪烁与强光爆闪；夜间灯光自动低亮度柔光；报警声音柔和逐级递增；硬件端无频闪、无强光、无高频刺激交互。

### 6. 发热监护模式（后续迭代）

一键开启，自动提升监测灵敏度，搭配家庭急救指引提示。

## 📋 三、非功能需求

| 类别 | 要求 |
|---|---|
| 准确性 | **低误报、低漏报优先级最高**；允许少量疑似提醒，杜绝高危漏检、杜绝高频无效报警 |
| 穿戴 | 完全无穿戴、无束缚，避免儿童抗拒、挣脱、不适 |
| 静音 | 全天候静默监测，不打扰睡眠，不新增发作诱因 |
| 安全边界 | 仅做辅助监护，无医疗诊断功能、不替代专业检查 |
| 药物适应 | 氯巴占等镇静类药物可能影响心率呼吸基线，调药时需重新矫正设备基线 |

## 🔬 四、技术可行性分析

- **脑电监测（暂不纳入）**：单电极误判率高；难以获取大量完整发作数据供 AI 训练；儿童头围变化难以标准化
- **视频 AI 分析（未来展望）**：利用家长录制的发作视频，结合 AI 分析面部表情、眼神、口唇动作等辅助判定发作类型
- **非惊厥发作（无报警需求）**：肌阵挛、失神等通常无心率血氧变化、伤害较小，仅作记录完善癫痫日记

## 👥 五、适用人群

设计始于 Dravet 患儿，可广泛适用于：各类婴儿起病难治性癫痫患儿、儿童隐匿性局灶性癫痫、发热诱发性癫痫儿童、分房独立睡眠的癫痫患儿、成人耐药性癫痫、合并发育障碍/自闭症/智力落后的癫痫人群、养老/康养/特教机构照护人群。
