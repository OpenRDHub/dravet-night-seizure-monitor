# Nighttime Seizure Monitoring Device · 夜间无感睡眠监测预警设备

> 项目5：Dravet 综合征夜间癫痫睡眠监测 —— [OpenRD 罕见病开源社区](https://github.com/OpenRDHub)

为癫痫患儿家庭打造夜间无感睡眠监测预警设备。

## 真实处境

部分 Dravet 等癫痫患儿的发作可能出现在睡眠中，而且有些发作非常隐匿，家属整夜无法安心睡觉。

## 挑战方向

- 融合体动、呼吸、心率、血氧等多模态信号
- 区分正常睡眠行为与异常发作
- 完成分级提醒与事件记录

## 关键词

`Dravet 综合征` `癫痫` `睡眠监测` `多模态信号` `分级预警`
