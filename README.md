# Nighttime Seizure Monitoring Device · 夜间无感睡眠监测预警设备

> 「罕见·无界」黑客松赛题 · 项目5：Dravet 综合征夜间癫痫睡眠监测设备
> 由 [OpenRD 罕见病开源社区（Khub）](https://github.com/OpenRDHub)发起 · 患者共创 · 一个赛题 = 一个长期开源项目

为 Dravet 综合征等癫痫患儿家庭打造**夜间无感睡眠监测预警设备**。

## 🧭 背景与真实处境

Dravet 综合征是婴儿期起病的罕见难治性癫痫性脑病，多数与 SCN1A 基因变异相关。部分 Dravet 等癫痫患儿的发作可能出现在**睡眠中**，而且有些发作**非常隐匿**——动作幅度小、被褥遮挡、无强直-阵挛表现，现有设备难以捕捉；其直接后果是：**家属整夜无法安心睡觉**，长期处于高度警觉状态。

## 📊 现有产品调研（社区已完成，2026-09）

| 产品 | 形态 | 监测信号 | 价格 | 主要局限 |
|---|---|---|---|---|
| Emfit MM | 床垫下传感器 | 体动 | $625 | 无法检测所有发作、无法确认是否癫痫 |
| Owlet BabySat | 智能袜 | 血氧 + 脉率 | $699 | 非癫痫专用，仅 1–18 月婴儿，仅美国 |
| Masimo Rad-97 | 床旁脉搏血氧仪 | 心率 + 血氧 | $2,490 | 处方设备，非癫痫专用 |
| SAMi | 视频动作监测 | 视频动作 | — | 受被子/环境干扰，网络要求高 |
| NightWatch+ | 上臂佩戴 | 心率 + 体动 + 体位 | $1,990 | 仅明显运动性发作，需佩戴上臂 |
| BoundaryCare | Apple Watch 平台 | 心率/血氧/跌倒/GPS | $1,589 | 非发作确认设备，依赖苹果生态 |
| EpiMonitor (EmbracePlus) | 手表 + App | 电活动 + 运动 | $399 + $17.4/月 | 仅强直-阵挛发作，需手机蓝牙 |
| EpiWatch | Apple Watch App | 运动 | $19.9/月 | 仅强直-阵挛发作，仅美国 |
| Inspyre | 智能手表 App | 重复晃动 + 心率 | $49.95/月 | 非为癫痫设计 |

**调研结论**：现有方案普遍价格高（$400–2,500 且多含订阅费）、以单一运动信号为主、对隐匿性夜间发作覆盖不足、国内可及性差。**低成本、多模态、无感佩戴的开源方案**存在明确空白。

## 🎯 挑战方向

- **多模态信号融合**：体动、呼吸、心率、血氧等信号融合，覆盖隐匿性发作
- **区分正常睡眠行为与异常发作**：降低假阳性（翻身、梦动不误报）与假阴性（隐匿发作不漏报）
- **分级提醒与事件记录**：按风险等级分级通知家属，自动记录事件供医生回溯

## ⚕️ 医疗与隐私原则

本项目是**辅助监测与提醒设备，不是诊断设备，不能替代医嘱与看护**；涉及儿童生理信号的采集与存储，须以隐私保护与安全为第一原则。
